# Heshna Nachiyar Suresh — Portfolio

A responsive single-page portfolio inspired by the structure and editorial feel of the reference portfolio, with original content and design.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `certificates` folder.
3. In GitHub: Settings → Pages → Deploy from branch → select `main` and `/root`.
4. Open the generated GitHub Pages URL.

## Included
- About
- Skills
- Projects
- Certifications
- Journey
- Contact / LinkedIn
- Responsive mobile navigation
- Scroll progress indicator
- Subtle reveal animations
